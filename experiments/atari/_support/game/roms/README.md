# Space Invaders ROM

The modified Space Invaders ROM is an external runtime input. Set `STACKPOMDP_SPACE_INVADERS_ROM` to its absolute path, or pass `--rom-path` to an Atari runner. The release does not contain or download ROM bytes.

The required SHA-256 and verification command are in the
[pretrained setup notes](../../../../../pretrained/README.md#external-space-invaders-rom).
